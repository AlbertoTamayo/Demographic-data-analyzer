# Demographic Data Analyzer

The demographic-data-analyzer.py file contains the main code that uses pandas to extract the data from adult.data.csv and turn it into a dataframe for later analysis. 
The test_module.py file contains various tests for the demographic-data-analyzer.py function that must be fulfilled in order to verify correct functionality of demographic-data-analyzer.py
The main.py file runs the demographic-data-analyzer and the test module automatically
